# Client-magnet acquisition

The public acquisition path is evidence-led:

`Homepage → real invitation preview or curated catalogue → template detail → guided builder`

The homepage and catalogue reuse published template records and the live preview route. They do not use invented product screenshots. Placeholder testimonials and the placeholder `.example` email were removed; customer quotes or prior work must not return until ML Printing supplies permitted, attributable material.

The two homepage catalogue calls pass through `/go/templates`, which records only the CTA source, fixed target, event type, and timestamp. It stores no IP address, user agent, cookie, profile, or guest identity, and only counts top-level browser navigation headers. The redirect uses an allowlisted destination rather than accepting an arbitrary URL.

Search support includes canonical/open-graph homepage metadata, Organization structured data, a dynamic sitemap of published templates, and robots rules that keep dashboards, builders, APIs, auth, and measurement redirects out of search indexes.

## Content governance

- Marketing may show published catalogue designs and explicitly permitted prior work.
- Political/campaign work is never added automatically.
- Guest names, RSVP records, and memory submissions are never marketing inputs.
- Claims must describe features that exist in the current release.
