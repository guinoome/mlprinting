# RSVP Intelligence

The organizer RSVP page now provides owner-scoped totals, attending headcount,
declined response count, guest/message search, status filtering, and an
owner-authorized CSV export. Guest-controlled CSV fields are quoted and
spreadsheet-formula neutralized.

This product currently accepts open responses and has no guest manifest.
Therefore pending is displayed as **Not tracked**, not a fabricated zero. A
future invited-guest roster can supply a real pending count without changing the
response filters or export contract.
